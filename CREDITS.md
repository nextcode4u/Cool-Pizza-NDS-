# Credits

## Original game

**Cool Pizza** was developed and released for iOS by **Secret Library** in 2012.
The original game's design, artwork, characters, music and identity come from
its creators.

| Credit | Creator |
| --- | --- |
| Original game | Secret Library and its development team |
| Primary design and artwork | Matthew Marchini |
| Original soundtrack | Tettix |

Matthew Marchini describes his role in the [original game portfolio](https://www.behance.net/gallery/20156229/Cool-Pizza-iPhone-Game).
Secret Library's [Unity announcement](https://discussions.unity.com/t/cool-pizza-free-ios-game/487174)
credits Tettix's soundtrack and describes the original game.

## Development tools

| Tool / project | Use |
| --- | --- |
| devkitPro / devkitARM | Nintendo DS compiler and build tools |
| libnds / calico | DS hardware interface and ARM7 runtime |
| maxmod | Audio streaming |
| libfat | Local score storage |
| melonDS | DS emulation and debugging |
| UnityPy | Unity asset parsing |
| dnfile / dncil | Managed metadata and IL parsing |
| Pillow | Sprite conversion |
| ffmpeg | Audio conversion |

The original iOS game used Unity, 2D Toolkit and iTween. This homebrew project
implements the DS runtime in C and prepares its assets from version 1.4.

## Original assets

Original game assets retain the rights and attribution of their creators.
The repository includes the prepared graphics, game data and audio needed to
build the DS ROM. These files come from Cool Pizza 1.4 and remain credited to
Secret Library, Matthew Marchini, Tettix and the original development team.
See [the build guide](docs/build.md) for their file locations.
